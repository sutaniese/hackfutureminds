PathWise — AI-платформа для старшеклассников, которая за 5 минут проводит пользователя от неопределённости к трём конкретным артефактам: осознанному карьерному выбору, финансовому маршруту и упакованному портфолио.

2. Проблема
67% выпускников казахстанских школ жалеют о выборе профессии (hh.ru Kazakhstan, 2024). Пропасть между школьниками и реальным рынком труда огромна по трём причинам:

#	Проблема	Следствие
1	Выбор профессии вслепую — по советам родных, мифам, а не данным рынка	Потеря лет на неподходящую специальность
2	Тысячи грантов и стипендий остаются невостребованными — о них не знают	Талантливые ребята отказываются от амбиций из-за финансов
3	Олимпиады и волонтёрство не упакованы на язык работодателей и вузов	Достижения теряются, конкурентное преимущество не реализуется


3. Решение — три модуля, один флоу
PathWise объединяет три задачи в единый бесшовный разговор. Ответы из шага 1 автоматически питают шаги 2 и 3 — пользователь не заполняет одно и то же дважды.

3.1  Модуль 1 — Осознанный выбор профессии
•	Пользователь проходит онбординг: 6–7 вопросов об интересах, предметах, достижениях
•	AI анализирует профиль и сравнивает с реальными карьерными траекториями специалистов
•	Выдаёт 3 карьерных пути с реальными зарплатами по рынку Казахстана
•	Опционально: подтягивает актуальные вакансии с hh.kz в реальном времени через web search

3.2  Модуль 2 — Финансовый маршрут
•	Пользователь указывает желаемый вуз и город
•	Система рассчитывает реальную стоимость студенческой жизни
•	Из базы 30+ грантов подбирает релевантные по профилю с конкретными суммами и дедлайнами
•	Показывает комбинацию финансирования, закрывающую gap (пример: Болашак $800/мес + DAAD $300/мес)

3.3  Модуль 3 — Упаковка достижений
•	Пользователь вводит достижения в сыром виде: '2 место на олимпиаде по физике'
•	AI переформулирует на язык вузов и работодателей с метриками
•	Пример: → 'Призёр республиканской олимпиады по физике (топ 3%, 340 участников)'
•	Готовый блок для резюме и мотивационного письма — за 30 секунд

5. Доступность (Accessibility)
PathWise проектируется с поддержкой пользователей с ограниченными возможностями — это уникальное конкурентное преимущество на хакатоне.

5.1  Для слабослышащих и немых — жестовое управление
•	Включённая камера распознаёт жесты рук в реальном времени
•	Реализуется через MediaPipe Hands (Google) — работает в браузере без сервера
•	Распознаёт 21 ключевую точку ладони, поверх — classifier на 5 жестов

5 поддерживаемых жестов для MVP:
Жест	Действие
Открытая ладонь	Открыть профиль / перейти на главную
Указательный палец вверх	Следующий шаг
Большой палец вниз	Назад
Сжатый кулак	Подтвердить выбор
V-жест (победа)	Вызвать помощь / подсказку

5.2  Для незрячих и пользователей без рук — голосовой режим
•	Полный голосовой флоу: вход через Web Speech API (ru-RU, kk-KZ)
•	Ответы озвучиваются через SpeechSynthesis API — никаких кликов не требуется
•	Claude API обрабатывает голосовой запрос и возвращает структурированный ответ
•	Совместимость с экранными читалками (ARIA-атрибуты на всех элементах)


6. Аппаратная часть (Hardware)
6.1  Raspberry Pi Киоск
Физический стенд для мест без компьютеров (сельские школы, библиотеки):
•	Raspberry Pi 4 + монитор + клавиатура/тачскрин
•	PathWise запущен в kiosk mode (Chromium fullscreen) — никакого лишнего UI
•	Работает как автономный терминал: пользователь подходит и проходит онбординг
•	Не требует личного устройства у пользователя

6.2  NFC Портфолио-карточка
Физическое воплощение достижений пользователя:
•	Пользователь завершает онбординг → получает персональную NFC карту
•	На карте записан уникальный ID профиля пользователя
•	Приложил к Pi → Pi читает ID → загружает профиль → отправляет на сервер
•	Опционально: Pi автоматически печатает одностраничное резюме
•	Метафора для питча: 'Твои достижения теперь материальны'

6.3  Отказ от концепта 35км диапазона
Концепт беспроводной передачи на 35 км (LoRa/Starlink) не реализуется в рамках хакатона — требует телеком-инфраструктуры. На питче используется формулировка: 'автономный киоск для мест без ПК', что честно и убедительно.

8. Архитектура и API
8.1  Флоу данных
1.	Пользователь отвечает на 6–7 вопросов онбординга (текст / голос / жесты)
2.	Фронтенд собирает все ответы в единый JSON объект
3.	Один POST запрос на /api/generate с полным профилем пользователя
4.	Backend формирует системный промпт + релевантные гранты из базы
5.	Claude API возвращает структурированный JSON с тремя артефактами
6.	Фронтенд рендерит три карточки результата одновременно

8.2  Структура API запроса/ответа
Входные данные (request body):
// POST /api/generate {   interests: ["биология", "химия"],   achievements: ["олимпиада по биологии, 2 место"],   target_university: "НУ, Астана",   city: "Астана",   budget_monthly: 80000,   language: "ru" }

Выходные данные (response JSON):
{   career_map: [     { title: "Биомедицинский инженер", salary: "450,000–700,000 KZT",       path: "...", vacancies: [...] }   ],   financial_route: {     monthly_cost: 180000,     grants: [{ name: "Болашак", amount: 120000, deadline: "..." }],     gap: 60000, coverage_percent: 67   },   portfolio_block: "Призёр республиканской олимпиады по биологии (топ 3%, 340 участников)" }

16. Дополнительные пользовательские сегменты
PathWise проектируется не только для школьников. Три дополнительных сегмента расширяют рынок и открывают B2B монетизацию.

16.1  Родители
Родители — скрытый decision maker. Именно они часто блокируют амбициозные цели ребёнка из-за страха перед финансами или незнания рынка.

Проблема сегмента
•	Принимают решения за детей, опираясь на устаревшие представления о профессиях
•	Не знают реальных зарплат и карьерных траекторий
•	Боятся отпускать ребёнка за рубеж из-за финансовой неопределённости
•	Не видят достижения ребёнка как конкурентное преимущество

Функционал для родителей
Фича	Описание
Родительский дашборд	Отдельный вход — видит профиль ребёнка, карьерную карту, финансовый маршрут. Без возможности редактировать, только наблюдать.
Финансовый калькулятор	Родитель вводит свой бюджет — система показывает точный gap и какие гранты его закрывают. Снимает страх перед стоимостью образования.
Сравнение профессий	Родитель вводит 'свою' профессию для ребёнка — AI честно показывает данные рынка: зарплата, спрос, перспективы через 5 лет.
PDF-отчёт для семьи	Одна кнопка — скачать полный отчёт по ребёнку для семейного обсуждения. Формат понятен взрослым без технического бэкграунда.

Ценность для родителя: 'Ваш ребёнок не выбирает наугад — вот данные, вот деньги, вот план.'


16.2  Учителя
Классные руководители и профориентационные педагоги — прямой канал выхода на школьников. Сейчас у них нет инструментов, только устаревшие тесты.

Проблема сегмента
•	Профориентация в школах сводится к тесту Голланда 1970-х годов
•	Нет инструмента для групповой работы с классом
•	Не могут системно отслеживать прогресс учеников
•	Достижения учеников нигде не агрегируются

Функционал для учителей
Фича	Описание
Учительская панель	Педагог создаёт класс, приглашает учеников по коду. Видит сводный дашборд: кто прошёл онбординг, у кого какие карьерные направления, кому нужна помощь с финансами.
Групповой онбординг	Учитель запускает сессию для всего класса — 30 учеников проходят за один урок (45 мин). Каждый получает свой результат.
Экспорт достижений класса	Агрегированный отчёт: сколько олимпиадников, какие направления популярны, кто нуждается в финансовой поддержке. Для директора.
Шаблоны рекомендательных писем	AI помогает написать рекомендательное письмо на основе профиля ученика — на казахском, русском, английском.

Ценность для учителя: 'Один инструмент заменяет устаревшую профориентацию и даёт результат для каждого ученика за один урок.'


16.3  Enterprise — Образовательные центры подготовки к ЕНТ
ЕНТ-центры — B2B сегмент с прямой монетизацией. Они работают с тысячами учеников и заинтересованы в поступаемости как ключевой метрике.

Проблема сегмента
•	Готовят к ЕНТ, но не помогают выбрать специальность — ученик поступает куда попало
•	Нет инструмента для массового портфолио-менеджмента учеников
•	Не могут показать родителям конкретный результат кроме баллов ЕНТ
•	Упускают гранты для своих учеников — это бьёт по репутации центра

Enterprise-функционал
Фича	Описание
